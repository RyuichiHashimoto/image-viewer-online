# Online Image Viewer

インターネット上の画像URLを指定枚数ぶん並べて表示する小さなWebアプリです。

## 起動

```bash
docker compose up -d
```

ブラウザで開きます。

```text
http://localhost:18088
```

## 使い方

- 基準画像URLと表示枚数を入力して「表示」を押します。
- 2枚目以降は、基準画像URL内の最後の数字を自動でインクリメントして表示します。
- キーボードの左右キー、または画面の左右ボタンでURL内の最後の数字を増減します。
- 増減量は表示枚数と同じです。
- 左キーは増加、右キーは減少です。
- 例: 表示枚数が4のとき、`image001.jpg` は左キーで `image005.jpg` になります。
- 画像が存在しない場合は、その枠にリンク切れとして表示します。
